Delhi Metro Dashboard – Power BI Project
## Project Overview
This project is an interactive Delhi Metro Dashboard developed using Microsoft Power BI. It helps analyze passenger journeys, fare collection, ticket types, trip patterns, and travel distances.
## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Dashboard Pages

### 1. Home
Introduction page with navigation buttons to access different dashboard pages.

### 2. Metro Overview
- Total Passengers
- Total Fare
- Average Distance
- Count of Trips
- Passenger by From Station
- Fare by Ticket Type
- Average Fare by Distance Range
- Fare Contribution by Source Station

### 3. Trip Analysis
- Trips by Remarks
- Trip Distribution by Remarks
- Average Fare Performance
- Passenger Analysis by Trip Remarks and Ticket Type

### 4. Key Insights
Summary of important findings from the dashboard.

## Key Insights
- Approximately 2K passengers across 100 trips.
- Total fare collection is 11.38K.
- Average journey distance is 5.27 km.
- Tourist Card contributes the highest fare share at 49.73%.
- Festival trips account for the highest trip share at 25%.
- Average fare performance is 113.77.
